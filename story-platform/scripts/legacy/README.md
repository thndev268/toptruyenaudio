# Legacy Scripts

Thư mục này chứa các script `fix_*`, `patch_*` cũ đã từng được sử dụng để vá lỗi hoặc cập nhật logic cho codebase trong giai đoạn phát triển trước. 

Các script này hiện **không còn được sử dụng** trong production hoặc CI/CD pipeline, vì các logic cần thiết đã được tích hợp trực tiếp vào source code chính (`story-platform/frontend` và `story-platform/backend`).

Tuy nhiên, chúng được giữ lại đây nhằm mục đích **tham khảo lịch sử** và tra cứu cách thức một số thay đổi phức tạp (như logic sync, cập nhật schema) đã được triển khai.

**Lưu ý:** Không chạy lại các script này.
